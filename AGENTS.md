# Agent instructions

- This is a public personal-site repository. Never commit local drafts, credentials,
  private details, or unpublished work; do not research or infer details about the owner.
- `drafts/` is private, gitignored, and development-only. Production writing lives in
  `src/content/posts/` only after the owner chooses to publish it.
- Publishing is manual. Do not add automatic deployment or publish externally without
  an explicit request. Keep the root `index.html` placeholder during setup.
- Keep the design dark, restrained, accessible, and writing-first. Use interaction only
  when it helps explain something.
- Do not invent personal content or links. Preserve unrelated worktree changes.
- Before handoff, run `./scripts/site build` and verify drafts are absent from `dist/`.
